# สิ่งที่ต้องแก้ไขจาก UI Audit (2026-10-14)

ผลตรวจ `apps/web` ทั้งแอป เทียบกับข้อกำหนดใน [PRODUCT.md](../PRODUCT.md) (WCAG 2.2 AA, desktop เท่านั้น) และ [DESIGN.md](../DESIGN.md)

**คะแนนรวม 14/20 (Good):** Accessibility 2 · Performance 3 · Theming 3 · Responsive 3 · Implementation Integrity 3

ระดับความรุนแรง:

- **P1** ผิด WCAG AA ต้องแก้ก่อนใช้งานจริง

## P2: แก้ในรอบถัดไป

- [x] **4. Modal ไม่มีชื่อให้ screen reader อ่าน** (WCAG 4.1.2)
  - ที่: `apps/web/src/components/modal.tsx:16`
  - วิธีแก้: ใส่ `aria-labelledby` ที่ `<dialog>` ให้ชี้ไปที่ `<h2>` ของหัวข้อ (สร้าง id ด้วย `useId()`)

- [x] **5. สถานะไมค์และกล้องในรายชื่อผู้เข้าร่วมเป็นไอคอนอย่างเดียว** (WCAG 1.1.1, 1.4.1)
  - ที่: `apps/web/src/components/meeting/room.tsx:446-447`
  - ปัญหา: ผู้ใช้ screen reader ไม่รู้ว่าใครปิดเสียงอยู่ และการบอกว่าใครกำลังพูดใช้แค่ขอบสี cyan
  - วิธีแก้: เพิ่มข้อความ `sr-only` เช่น "muted" และ "camera off"

- [x] **6. กล่องแจ้งเตือน (กระดิ่ง) ปิดด้วยคีย์บอร์ดไม่ได้** (WCAG 2.1.1)
  - ที่: `apps/web/src/components/notification-bell.tsx:36-71`
  - ปัญหา: ปิดได้เฉพาะการคลิกเมาส์นอกกล่อง กด Escape ไม่ปิด และกด Tab ออกไปแล้วกล่องยังค้าง
  - วิธีแก้: ปิดเมื่อกด Escape หรือเมื่อ focus ออกจากกล่อง แล้วคืน focus ไปที่ปุ่มกระดิ่ง

- [x] **7. Toast หายเองตามเวลา รวมถึงข้อความ error** (WCAG 2.2.1)
  - ที่: `apps/web/src/components/toast.tsx:23`
  - ปัญหา: error หายใน 8 วินาที ข้อความอื่นหายใน 5 วินาที โดยไม่หยุดนับเมื่อเอาเมาส์ชี้หรือ focus อยู่ และ error ประกาศแบบ `polite`
  - วิธีแก้: หยุดนับเวลาเมื่อ hover หรือ focus ให้ error ค้างจนกว่าผู้ใช้จะปิดเอง และประกาศ error ด้วย `role="alert"`

- [x] **8. ขอบช่องกรอกจางเกินไป** (WCAG 1.4.11)
  - ที่: `apps/web/src/components/ui.tsx:50,61` และ `room-code-input.tsx:54`
  - ปัญหา: ขอบ `line` เทียบกับพื้น canvas ได้ 1.72:1 (ต้องได้ 3:1) ทำให้มองช่องกรอกและช่องรหัสห้อง 4 ช่องไม่ค่อยเห็น
  - วิธีแก้: ใช้ `line-strong` เป็นสีขอบของ input

- [x] **9. แถบระดับเสียงไมค์ทำให้หน้า pre-join render ใหม่ 60 ครั้งต่อวินาที** (Performance)
  - ที่: `apps/web/src/components/meeting/prejoin.tsx:53`
  - ปัญหา: `setLevel` ทำงานทุกเฟรมและ re-render ทั้งหน้า pre-join รวม dropdown และภาพกล้อง ทำให้เปลือง CPU บนเครื่องสเปกต่ำ
  - วิธีแก้: แยกแถบระดับเสียงเป็น component เล็ก ๆ ของตัวเอง หรือเขียนความกว้างผ่าน ref แทน state

4. **ข้อ 11–13** (`/impeccable animate`, `/impeccable adapt`, `/impeccable polish`)

## สิ่งที่ดีอยู่แล้ว ควรรักษาไว้

- Modal ใช้ `<dialog>` ของเบราว์เซอร์ จึงได้ focus trap และการปิดด้วย Escape มาเลย มี `lang="en"` และเส้น focus สี cyan ทั้งแอป และทุกหน้ามี `h1` หน้าละหนึ่งตัว
- ปุ่มที่มีแต่ไอคอนมีชื่อครบ ช่องกรอกมี label จริงทุกช่อง และ error ประกาศด้วย `role="alert"`
- สีมาจาก design token เกือบทั้งหมด มี hard-code แค่ `text-red-200` และ `text-red-300`
- สถานะ Recording ตรงกับ server จริง และสีเขียว "Ready" แสดงเฉพาะเมื่อตรวจไฟล์ในที่เก็บแล้ว
